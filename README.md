# 🎙️ Voice Assistant

**Voice Assistant** is a web-based application that allows users to interact with a system using voice commands. The application converts spoken words into text, processes the command, and provides an appropriate response.

## 🚀 Features

- 🎤 Voice command recognition
- 🗣️ Speech-to-text conversion
- 🔊 Text-to-speech response
- 💬 Interactive voice-based communication
- 🌐 Open websites using voice commands
- 🕐 Get date and time information
- 🔎 Perform voice-based searches
- 📋 Execute basic system commands
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – User interface and responsive design
- **JavaScript** – Application logic
- **Web Speech API** – Speech recognition and speech synthesis

## ⚙️ How It Works

```text
User speaks a command
        ↓
Speech Recognition
        ↓
Speech converted to text
        ↓
Command processing
        ↓
Action performed
        ↓
Voice/Text response
```

## 💡 Example Commands

```text
"Open Google"
"What is the time?"
"Search for Python tutorials"
"Read this text"
```

The assistant recognizes the command and performs the corresponding action or provides a response.

## 🎯 Objective

The main objective of this project is to create a simple and interactive **voice-controlled web application** that demonstrates speech recognition, natural user interaction, and speech synthesis using frontend web technologies.
